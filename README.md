# Dostaffkin

Веб-приложение на Angular для оформления и отслеживания доставки посылок. В форме можно указать маршрут, выбрать размер посылки и скорость доставки, а затем рассчитать ориентировочную стоимость.

**[Открыть сайт](https://dariadarsonina.github.io/dostaffkin/)**

## Возможности

- Подсказки при вводе адресов и отображение маршрута на карте.
- Расчёт расстояния, срока и стоимости доставки.
- Отправка заявки и отслеживание посылки по трек-номеру.

## Технологии

Angular 21, TypeScript, RxJS, Яндекс Карты и GitHub Pages.

## Локальный запуск

Понадобятся Node.js 22 (от 22.12) и npm. В папке проекта выполните:

```bash
npm ci
npm start
```

Откройте `http://localhost:4200`. Для сборки проекта выполните `npm run build`.
